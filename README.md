## 人机协同三反思

### 1. 意图清晰度反思

今天有两次的结果一开始跟我想的不一样，回头看都是提示词要素缺了。

第一次是排错那次。我写了角色、目标、约束、验收标准，看起来很齐全，但我把"报错堆栈 `index.html:68:15`"当成事实抄进去了，结果 AI 打开文件发现第 68 行是一段 CSS，全站根本没有 `resetAnimation` 这个函数——**我缺的不是四要素里的某一项，而是"约束里的证据本身是假的"**。我以为把报错原样贴出来就是最精确的描述，其实那行号来自另一份文件。后来我是这么补的：不再要求它"照堆栈修"，改成"你自己找出来自己改吧"，让它先复现、自己定位、再修，把"找问题"这一步也明确划进任务里，它才动手建了一个演练页面并修好，控制台 0 报错。

第二次是天体预设这个任务。我只写了角色、工程目标、技术约束，**漏了【验收标准】**，而且没发现"要太空（g=0）"跟我上午定的"重力滑块 1~25"是互相打架的。AI 做完后主动把这两件事报给我：一是没有验收标准它就自己定了一套可量化的（补间要逐帧连续、刷新要能读回原值），二是滑块下限必须从 1 放宽到 0。我这才明白，验收标准不只是"考它"，更是给它一把尺子——不然它只能替我猜。以后我打算把"跟已有功能冲突时允许改哪一处"也写进约束里。

### 2. 闭环控制反思

我今天定位问题主要靠两条土办法。一条是**别看画面漂不漂亮，看数字对不对**：双摆拖尾不出现的时候，我让 AI 去查它每帧存进轨迹数组的坐标，发现它存的是整段两个球的位置、画的却去读单个点的 `.x/.y`，算出来是一堆 NaN，浏览器就静悄悄什么也不画——不报错，但功能没了。另一条是**承认我看不懂公式，但可以要求它给出公式正确的证据**：双摆那四个微分方程的推导我一行都跟不上，AI 就没有让我看推导，改成跑 133.9 秒看机械能漂移，结果是 0.0000%，我才接受"这个积分器是准的"。g=0 时理论周期显示"∞（失重·无恢复力）"而不是 NaN，也是同一类边界条件的检查。

AI 的修复方案我看懂了一半。物理公式本身（RK4 四阶积分、阻尼写成"每 1/60 秒速度乘 (1−c)"）我看不懂，但我看懂了它**为什么这样改**：阻尼如果按帧数衰减，帧率一掉摆动就会变快或变慢，所以必须跟时间绑定而不是跟帧绑定。这一点它用大白话给我讲清楚了。

也有 AI 自己判断错、被我拽回来的时候：它有一次看到我点重置后"已运行"还在涨，就下结论说复位没清计时器；后来它自己重测（109.8 秒归到 17.2 秒）并当面更正了——真实原因是工具来回一次要十几秒，页面读数当然会继续走。这件事对我启发很大：**闭环里人不能只签字，得盯它取证据的过程**。还有一次动画完全停滞，是因为浏览器面板被收起、页面处于 hidden 状态，AI 用"假时钟"逐帧手动推进才把补间曲线量出来，这种排查思路我自己绝对想不到。

### 3. 主体地位确认

**我定的核心决策**：功能范围——要三个滑块还是四个按钮、摆长 100~350 像素、阻尼上限 0.010、重置必须精准回到 45 度；审美——深色质感不许动，胶囊按钮要亮起来那一个；取舍——我明确说"不用改了，推进到最后的验证步骤"，也说过仓库名"不用改了"；流程——每周验收通过就打一个带名字的基线存档点（tag），学期末攒够 16 个做答辩，这个规矩是我提出来的；验收——我要求它逐条给实测数据，只说"已完成"我不签。以及**只有我能做的动作**：注册 GitHub、生成和撤销访问令牌、在网页上建仓库、改权限、打开浏览器面板，这些 AI 碰不了。

**AI 完成的重复劳动**：环境检查和 git 命令、写 HTML/CSS/JavaScript、查 API 文档、起本地临时服务器、在浏览器里点按钮采样读数、把证据整理成表格、写 commit 说明和 tag 说明、以及每做完一步把术语（仓库、commit、.gitignore、localStorage、防抖、补间）翻译成大白话讲给我听。

说到底，我在回路上的位置是**"提要求 + 定标准 + 保留回滚权"**：它每通过一次验收就留一个能一键回去的存档点，我不满意可以退回上午那一版（`week05-interactive-baseline`），所以我不需要为它的每次试错担心，只需要为我的每一次需求描述负责。
