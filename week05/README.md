## 六、（选做）进阶挑战说明

1. **多天体物理对照**：四个预设取真实表面重力（地球 9.80 / 月球 1.62 / 木星 24.79 / 太空 0），学生可直观验证小角度周期 `T = 2π√(L/g)`——同一摆长 2.00 m 下，地球 2.84 s、木星 1.78 s、月球 6.97 s，与 HUD 读数一致。
2. **失重边界处理**：g=0 时系统无恢复力矩，周期在数学上发散，界面显式呈现"∞（失重·无恢复力）"而非 `Infinity` 或 `NaN`，摆球按惯性越过水平位置持续转动（截图 03 中 θ₂ 已达 -114.2°）。
3. **状态持久化设计**：写入采用 400 ms 防抖，避免拖滑块时高频写盘；读取时对三个参数分别做区间钳制（100~350 / 0~25 / 0~0.01）并校验 `Number.isFinite`，缓存被手工改坏也不会让页面崩溃；若数值不匹配任何预设则回退为"自定义"，不伪造高亮状态。
4. **可扩展为双摆**：同目录 `week07/index.html` 是把本单摆升级为混沌双摆的进阶版本（拉格朗日方程 + RK4 定步长 1/480 s 积分 + 320 点彩虹衰减拖尾 + 指针拖拽摆球设定初角）。实测运行 17.8 s：θ₂ 累计 584.2°（出现完整翻转，混沌特征），机械能 17.069 J、漂移 -0.0000%（见截图 05）。
